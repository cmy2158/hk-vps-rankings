## 下单前确认的四件事

这四点都写在条款或套餐页的角落里，但每一处都可能影响实际体验。

1. **流量是单向还是双向合计。** 这是最容易踩的坑。野草云在官方说明里写明，新套餐的高速流量按入站与出站合计统计，用完后按套餐标注的“超额后”速率不限流量继续用；老套餐则是超量后限速 1Mbps，到次月 1 号重置。MKCloud 的流量规则在套餐页和服务条款里，重点确认入站流量是否计入。

2. **带宽写的是峰值还是保证值。** 国际线路标 500M 通常是共享峰值，晚高峰未必跑满；大陆优化线路给 100-200M 是常态。

3. **优惠码在结算页填。** MKCloud 用的是常见的 WHMCS 面板，优惠码在结算页底部的 "Have a promo code?" 输入框里填。各家码的适用范围不一样，有的全场通用，有的只限特定机房或机型，下单前看清范围，不同类型的码不能混用。

4. **免备案不等于没有要求。** 香港服务器不需要 ICP 备案，这是它相对大陆服务器最大的便利。但商家有自己的风控：野草云的条款写明平时不强制实名，一旦账户被认为存在风险就必须提供有效证件，并且不能通过 VPN 等匿名网络下单。注册时用真实资料，能省掉很多麻烦。
